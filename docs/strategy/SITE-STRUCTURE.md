## Linking rules

- Homepage links to all six service hubs and the four highest-value concern pages.
- Each service hub links to its relevant conditions/treatments and back to the parent service overview.
- Each condition page links to the appropriate service, one or two related conditions, one supporting article, and contact/booking.
- Articles link to a relevant commercial page only where the next step is clinically appropriate.
- Breadcrumbs mirror the hierarchy and use canonical URLs.
- Add a page to the sitemap only when it is indexable, canonical, complete, and returns HTTP 200.

## Location-page rule

Start with Nallagandla as the primary location signal and a single west-Hyderabad service-area section. Create another location page only when it has demonstrably unique local value, evidence, and demand. Never clone a page by changing the suburb name.
